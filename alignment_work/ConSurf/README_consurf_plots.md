# ConSurf Plot Generation — CTCF Analysis

This document describes the full workflow used to run ConSurf and generate the annotated conservation plots for Human CTCF.

---

## Overview

Three ConSurf runs were performed:
1. **Full alignment** (50-sequence subset): all species combined, Human CTCF as query.
2. **Vertebrates-only** (32 sequences): Human CTCF as query.
3. **Invertebrates-only** (37 sequences): *Ciona intestinalis* as query.

---

## Input Alignment

- Source: `C:\Users\Nat\Downloads\updated_alignment_0611.fas`
- 69 species total.
- Split point: `Ciona_intestinalis` separates vertebrates (above) from invertebrates (below).

## Environment Setup

ConSurf requires a Linux/Perl environment. Runs were executed inside **WSL Ubuntu** as `root` to avoid sudo prompts.

### Dependencies installed in WSL

```bash
apt-get install -y perl libconfig-inifiles-perl bioperl libdbi-perl libdbd-mysql-perl
```

### Rate4Site compilation

Rate4Site (bundled legacy C++) was patched for modern `g++` compatibility and compiled inside WSL:

```bash
cd /root/consurf_nospace/third_party/rate4site.3.2.source_fast/sourceMar09
g++ -O2 -o rate4site *.cpp
```

Patches applied to source files (`errorMsg.cpp`, `someUtil.cpp`, `rate4siteOptions.cpp`, `fromInstructionFile.cpp`):
- Replaced `_errorOut != cerr` with pointer comparison `_errorOut != &cerr`.
- Replaced `ifstream == NULL` checks with `!stream`.

### Perl compatibility patch

ConSurf `consurf` script (Perl) was patched for Perl 5.38:
- Replaced `defined(@array)` with `scalar(@array) > 0`.
- Removed unsupported `-n 32` option from Rate4Site command.

### No-space shim

The ConSurf repo was copied to `/root/consurf_nospace/` to avoid shell command failures from the Windows mount path containing spaces.

### Config file

`/root/ctcf_consurf_run/consurfrc.local` — custom ConSurf config pointing to WSL paths.

## Run 1: Full Alignment (50-sequence subset)

ConSurf rejected the full 69-sequence MSA due to a memory guard; a 50-sequence reduced version was used.

```bash
export CONSURFCONF=/root/ctcf_consurf_run/consurfrc.local
perl /root/consurf_nospace/consurf \
  -MSA /root/ctcf_consurf_run/input/ctcf_alignment_reduced50.fasta \
  -SEQ_NAME Human_CTCF \
  -Out_Dir /root/ctcf_consurf_run/output \
  -w /root/ctcf_consurf_run/work
```

**Output copied to:** `ConSurf/output/ctcf_consurf_run/`

Key files:
- `Human_CTCF_consurf.grades`
- `Human_CTCF_ColoredSeq.html`
- `Human_CTCF_Tree.txt`
- `msa_aa_variety_percentage.csv`

## Plot Generation

All plots were generated with `plot_consurf_grades.py` (workspace root).

### Grade file format

The `.grades` file columns used:
- `POS`: residue position in query sequence.
- `SEQ`: amino acid.
- `SCORE`: normalized conservation score (more negative = more conserved).
- `COLOR`: grade 1–9 (9 = most conserved, 1 = most variable).

### Annotation modes

The script supports two annotation modes (via `--annotation-mode`):

| Mode | ZF ranges | Lysine linker | YDF |
|---|---|---|---|
| `human` (default) | Hard-coded human CTCF residues | Hard-coded 229–265 | Sequence-derived |
| `sequence` | Inferred from C2H2 motif scan | Inferred between YDF and ZF1, or overridden | Sequence-derived |

Manual linker override is also supported:
```
--linker-start 220 --linker-end 244
```

### Human CTCF domain coordinates (hard-coded)

| Feature | Residues |
|---|---|
| YDF motif | 226–228 |
| Lysine linker | 229–265 |
| ZF1–ZF11 | 266–288, 294–316, 322–344, 350–372, 379–401, 416–438, 444–466, 472–494, 502–524, 530–552, 558–580 |

### Ciona intestinalis lysine linker (user-specified)

| Feature | Residues |
|---|---|
| Lysine linker | 220–244 |
